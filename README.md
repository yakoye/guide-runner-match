一个为视障跑者（盲友）与陪跑志愿者量身打造的**纯前端、零服务器**的智能排班与配对工具。通过直观的拖拽和智能算法，将原本需要在 Excel 中耗费大量时间的“查状态、找对应、排名单”工作，简化为极其优雅的“一键预处理 + 拖拽微调”。

## 🛡️ 核心承诺：绝对的数据安全与隐私保护

本项目专门针对公益活动中涉及的敏感个人信息（姓名、年龄、身份证号、手机号等）进行了**最高级别的隐私设计**：

* **🚫 零云端上传**：本项目是一个纯粹的单文件 HTML / 本地前端应用，**没有任何后端服务器，没有任何 API 请求**。
* **💻 100% 本地运算**：您拖入的所有 Excel 报名表、盲友状态数据，全部在您当前电脑的浏览器（内存）中进行解析、匹配和渲染。
* **🔒 数据阅后即焚（除脱敏经验值外）**：刷新页面或关闭浏览器后，所有人员敏感名单瞬间清空，绝不留痕。仅有志愿者的“打卡次数（经验值）”会以脱敏形式保存在您当前浏览器的 `LocalStorage` 中。

无论您将本文件发给哪位领队或同事，只要双击在本地浏览器打开，就能实现**物理隔离级别的数据安全**。

## ✨ 核心特性

* **⚡ 智能识别与预配对**：拖入任意包含报名数据的 Excel/CSV，自动清洗并提取队伍、性别、意向分组。优先根据“同性别优先”、“老带新（经验值高优先）”原则自动完成预配对。
* **🧠 本地经验值沉淀**：内置持久化的人员库。每次成功配对并复制发布文案后，自动为出勤人员增加经验值。超过 180 天未参加活动的志愿者，配对时系统会自动提示“久未跑降级”。
* **🖱️ 丝滑的拖拽排版**：全面支持 `SortableJS`，在配对台上任意拖拽盲友排序，最左侧自然序号（1, 2, 3...）自动递增，最下方发布文案瞬间同步。
* **🔄 动态对换与防冲突**：下拉框分配志愿者时，若选择已被分配的志愿者，系统会自动执行“换人对调”逻辑，防止同一人分饰两角。
* **📝 所见即所得的微信排版**：支持自定义全局群发模板（支持本地记忆保存），一键生成排版精美、带序号、带短标注的纯文本，直接粘贴至微信群。

## 🚀 快速开始

本项目无需任何繁琐的 Node.js 环境安装或 npm 构建，**开箱即用**。

- 方法一：
	- 1.点击[这里](https://yakoye.github.io/guide-runner-match/guideRunnerMatch.html)，进入网页版。
	- 2.将包含“报名数据”和“状态数据”的 Excel 表格（支持 `.xlsx`, `.csv`）**直接拖拽**到网页中心的上传区域。
	- 3.在顶部下拉框选择您要排表的队伍，即可开始享受高效的配对体验！
  
- 方法二：

	- 1.克隆或下载本仓库。

	- 2.找到根目录下的 `guideRunnerMatch.html` 文件（或您重命名的 `.html` 文件）。

	- 3.**双击文件**，使用 Google Chrome 或 Microsoft Edge 浏览器打开。

  - 4.继续方法一的步骤2和步骤3.
  
  

## 🛠️ 技术栈与依赖

为了极致的便携性，本工具通过 CDN 引入以下优秀的开源库：
* **框架**: [Vue 3](https://vuejs.org/) (组合式 API)
* **UI 组件**: [Element Plus](https://element-plus.org/)
* **Excel 解析**: [SheetJS](https://sheetjs.com/) (无惧脏数据与科学计数法)
* **拖拽引擎**: [SortableJS](https://sortablejs.github.io/Sortable/)

## 💡 使用建议

* **日常操作流**：拖入表格 -> 选队伍 -> 点击【一键智能预配对】 -> 手动检查异性/特殊备注并微调 -> 拖拽排好队形 -> 点击【一键复制】发群。
* **人员重名处理**：底层已引入内部 `UID` 机制，即使存在重名的志愿者或盲友，系统也可稳定追踪，拖拽不乱序。
* **模板占位符**：在发布模板中，请务必保留 `【配对列表】` 这四个字，系统会自动将最终的排班表替换进此处。
